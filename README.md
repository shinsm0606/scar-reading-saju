# 흉터까지 읽는 사주

생년월일과 출생시간을 바탕으로 반복되는 행동 패턴과 주의점을 직설적인 보고서 형식으로 보여주는 한국어 반응형 웹 애플리케이션입니다.

> 이 버전은 **실제 만세력 계산이 아닌 데모 분석**입니다. 전통 명리학 용어를 UI와 규칙 기반 해석 구조에 활용하지만, 실제 음양력 변환·절입 기준 월주·진태양시 보정은 수행하지 않습니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

```bash
npm run test
npm run lint
npm run build
npm run build:pages
```

GitHub Pages 전용 로컬 실행은 `npm run dev:pages`를 사용합니다. 정적 배포 결과는 `docs/`에 생성되며, 공개 주소는 `https://shinsm0606.github.io/scar-reading-saju/`입니다.

## 구현 기능

- 시작 화면, 입력 폼, 단계별 분석 연출, 전체 결과 보고서
- 이름, 성별, 양력/음력, 윤달, 생년월일, 시간 미상, 지역, 풀이 강도 입력
- 존재하지 않는 날짜와 미래 날짜 검증
- `FortuneCalculator` 인터페이스 기반 결정론적 데모 계산
- 년주·월주·일주·시주, 오행/음양/십신 분포, 신강·신약 참고값, 합·충 참고, 분석 신뢰도
- 조건·심각도·신호·결과·행동 수칙을 가진 8개 규칙 데이터 모듈
- 결과 문장 중복 제거와 3단계 어조 변환
- 접기/펼치기, 스크롤 등장, 위험 도장 애니메이션
- 텍스트 복사, 개인정보 없는 공유 URL, 세로형 PNG 저장
- 선택적 LocalStorage 저장 및 삭제
- 개발 테스트에서 서로 다른 5개 입력 프로필 검증

## 계산 방식과 교체 지점

`app/types/fortune.ts`의 `FortuneCalculator`가 계산기 계약입니다. 현재 구현체는 `app/lib/fortuneCalculator.ts`의 `DemoFortuneCalculator`입니다. 실제 만세력으로 교체할 때는 이 클래스의 `calculate(input)`을 실제 계산 어댑터로 바꾸되 `FortuneChart` 형식을 유지하면 UI와 해석 엔진을 그대로 사용할 수 있습니다.

실제 계산 도입 시 반드시 다음을 검증해야 합니다.

1. 음력·양력과 윤달 변환
2. 절기 절입 시각 기준 월주
3. 출생 지역과 시간대, 필요 시 진태양시 보정
4. 야자시 처리 정책
5. 시주, 십신, 지장간, 합·충·형·파·해 계산
6. 테스트 벡터 및 원전/만세력 결과 대조

## 라이브러리와 라이선스

이 버전은 사주/만세력 외부 라이브러리를 사용하지 않습니다. 계산 결과를 실제 명식으로 오인시키지 않기 위해 화면에 항상 “데모 분석”을 표시합니다.

주요 런타임/개발 도구:

- React — MIT
- TypeScript — Apache-2.0
- Vite — MIT
- Tailwind CSS — MIT
- Vitest — MIT
- Vinext / Next.js 호환 실행 구조 — 각 패키지 라이선스는 설치된 패키지 메타데이터 참조

## 개인정보와 한계

- 입력값은 외부 서버로 전송하지 않습니다.
- 사용자가 저장에 동의한 경우에만 브라우저 LocalStorage에 저장합니다.
- 공유 링크와 이미지에는 생년월일, 출생시간, 출생 지역을 넣지 않습니다.
- 결과는 자기 성찰용 콘텐츠이며 의료·법률·재무 판단이나 미래 사건의 확정을 대신하지 않습니다.
- 공유 이미지에는 QR 코드 대신 현재 서비스 주소 영역을 넣습니다.
