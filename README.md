# 흉터까지 읽는 사주

생년월일과 출생시간을 바탕으로 반복되는 행동 패턴과 주의점을 직설적인 보고서 형식으로 보여주는 한국어 반응형 웹 애플리케이션입니다.

원국 계산은 MIT 라이선스의 `manseryeok` 2.0.0을 사용합니다. 한국천문연구원(KASI) 정본 음력 데이터, 한국 표준시, 입춘·절기 절입 시각을 기준으로 연주·월주·일주·시주를 계산합니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

```bash
npm run test
npm run lint
npm run build
npm run build:pages
```

GitHub Pages 전용 로컬 실행은 `npm run dev:pages`를 사용합니다. 정적 배포 결과는 `docs/`에 생성되며, 공개 주소는 `https://shinsm0606.github.io/scar-reading-saju/`입니다.

## 구현 기능

- 시작 화면, 입력 폼, 단계별 분석 연출, 전체 결과 보고서
- 이름, 성별, 양력/음력, 윤달, 생년월일, 시간 미상, 지역, 풀이 강도 입력
- 관계·직업·재물·생활 고민 분야와 최대 600자의 선택형 질문 입력
- 존재하지 않는 날짜와 미래 날짜 검증
- `FortuneCalculator` 인터페이스 기반 실제 만세력 계산
- 년주·월주·일주·시주, 오행/음양/십신 분포, 신강·신약 참고값, 합·충 참고, 분석 신뢰도
- 양력·음력·윤달 변환, 절기 절입 기준 월주, 선택적 진태양시 보정
- 오행 과다·부족 10종, 일간 10종, 십신 10종과 분야별 세부 규칙을 조합하는 해석 엔진
- 실제 오행 수치, 일간, 십신 빈도, 신강·신약 편차를 점수화한 차트별 규칙 우선순위
- 고민 분야·문장 속 핵심어와 원국의 상위 약점을 교차하는 집중 풀이
- 결과 문장 중복 제거와 3단계 어조 변환
- 접기/펼치기, 스크롤 등장, 위험 도장 애니메이션
- 텍스트 복사, 개인정보 없는 공유 URL, 세로형 PNG 저장
- 선택적 LocalStorage 저장 및 삭제
- 개발 테스트에서 서로 다른 5개 입력 프로필 검증

## 계산 방식

`app/types/fortune.ts`의 `FortuneCalculator`가 계산기 계약이며, 구현체는 `app/lib/fortuneCalculator.ts`의 `KoreanManseCalculator`입니다.

- 양력 1800–2300년, 음력 1800–2100년 사주 계산
- KASI 정본 기반 한국 음력·윤달 변환
- 입춘 절입 순간 기준 연주, 절기 경계 기준 월주
- 한국 표준시 기준 일주와 시주
- 선택 시 국내 주요 도시 경도, 균시차, 과거 표준시·서머타임을 반영한 진태양시 보정
- 출생 시각은 시·분을 1분 단위로 입력
- 원국 화면은 한국 만세력 표의 일반적인 시주·일주·월주·년주 순서로 표시
- 자시 일 경계는 라이브러리 기본값인 자정 기준

오행 분포는 원국의 천간과 지지를 각각 1개로 집계합니다. 신강·신약 점수와 합·충·형·파·해 표시는 해석을 위한 참고 지표이며 `manseryeok`이 반환한 원국 자체를 변경하지 않습니다.

해석은 일간을 중심으로 오행·십신·강약·지지 관계를 한꺼번에 비교한 뒤 관찰 가능한 생활 장면과 행동 수칙으로 번역합니다. 용신, 12운성, 대운·세운은 현재 계산 범위에 포함하지 않으며 정확한 계산값처럼 표시하지 않습니다.

## 개인정보와 한계

- 입력값은 외부 서버로 전송하지 않습니다.
- 사용자가 저장에 동의한 경우에만 브라우저 LocalStorage에 저장합니다.
- 공유 링크와 이미지에는 생년월일, 출생시간, 출생 지역, 입력한 고민 내용을 넣지 않습니다.
- 출생시간을 모르면 년주·월주·일주만 계산하고 시주는 표시하지 않습니다.
- 결과는 자기 성찰용 콘텐츠이며 의료·법률·재무 판단이나 미래 사건의 확정을 대신하지 않습니다.
- 공유 이미지에는 QR 코드 대신 현재 서비스 주소 영역을 넣습니다.
